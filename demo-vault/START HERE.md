# Visual Gantt Demo
by LanternSquid

This vault contains Visual Gantt for Bases v0.7.0 and fictional project notes. It requires Obsidian 1.15.1 or newer on desktop.

Enable Visual Gantt for Bases in Settings → Community plugins. Open `01 - Valid Project.base` for the timeline, or `02 - Validation Errors.base` for deliberately broken tasks. The valid project has 12 tasks, 13 dependencies, and four milestones. The validation sample has seven warnings and six drawn tasks.

Try Day, Week, and Month zoom, Task width, Today, Project, PNG, and PDF in the toolbar. Exports appear in `Visual Gantt Exports` inside this vault.

Date editing starts off. To test it, open the Base view menu, click the arrow beside the view name, and enable experimental date editing. Move Firewall policy audit one day later to propose December 9–12. Save and Undo to restore December 8–11. Moving it one day earlier must be rejected because Inventory finishes on December 7.

See the release README and `docs/QA.md` for limitations and additional tests.
